# Remix Icon (local)

[Remix Icon](https://github.com/Remix-Design/RemixIcon) v4.6.0 — Apache 2.0.

Файлы:

- `remixicon.css` — классы `ri-*`
- `remixicon.woff2` — шрифт иконок

Обновление: скачать новую версию с [npm remixicon](https://www.npmjs.com/package/remixicon) или [GitHub releases](https://github.com/Remix-Design/RemixIcon).

Использование:

```html
<i class="ri-tools-line" aria-hidden="true"></i>
```

В Mini Garage — обёртка `ds-icon` из `design-system/foundations/icons.css`, хелперы в `js/icons.js`.
